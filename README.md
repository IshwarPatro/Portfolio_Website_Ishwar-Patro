## 🎨 Design Philosophy: Neo-Noir Atmospheric Engine

The portfolio features a custom **Neo-Noir Atmospheric Engine**:
- **Procedural Canvas Drizzle**: Real-time diagonal rain particle simulation with wind deflection.
- **Chiaroscuro Nocturnal Stratum**: Deep inky obsidian palette (`#05070c`) accented with sodium amber and cyan neon reflections.
- **Smoked Obsidian Glassmorphism**: Ultra-dark, frosted glass cards (`backdrop-filter: blur(28px)`) with razor-thin specular edge highlights ensuring 100% legibility on all devices.
- **Interactive Cyber CLI Terminal**: Direct in-browser shell simulator supporting `skills`, `projects`, `telemetry`, `whoami`, `contact`, and `clear`.
- **Web Audio Synth**: Real-time 55Hz sub-bass ambient drone generator built with the native Web Audio API.
- **Mobile Responsive**: Zero horizontal overflow, optimized touch targets, and full edge-to-edge readability across all viewports down to 320px.

## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/IshwarPatro/Portfolio_Website_Ishwar-Patro.git
cd Portfolio_Website_Ishwar-Patro

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Compile optimized static export
npm run build
```

## 📦 Deployment

The project is compiled using Next.js static export (`output: 'export'`) and deployed globally to **Cloudflare Workers** via static asset bindings.

```bash
# Deploy static assets to Cloudflare Workers
npx wrangler deploy
```
